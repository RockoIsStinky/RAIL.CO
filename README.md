# RAIL.CO
A work-in-progress train-making game made for Crossroads HC! You build a train, run it on the railway, and share your license plate with your friends 


# BULD & RUN IT
1. A GitHub page will be up soon! But for now, we gotta stick with this:
`git clone https://github.com/RockoIsStinky/RAIL.CO.git`
2. Go to the project's directory; this will depend on where you cloned it: 
`cd RAIL.CO`
3. Install NPM: `npm install`
4. Host it locally: `npx vite` or `npm run dev`; both works
5. Terminal output will be something like 
```
  VITE v8.3.8  ready in 259 ms

  ➜  Local:   http://localhost:1234/ <- open this url
  ➜  Network: use --host to expose
  ➜  press h + enter to show help

```
